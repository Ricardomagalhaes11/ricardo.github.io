# London Global University 🌍🎓

Bem-vindo ao repositório oficial do website da **London Global University**!

Este site foi criado com o objetivo de fornecer informações institucionais, académicas e administrativas a estudantes, docentes e visitantes.

## 🔍 Funcionalidades previstas

- Página inicial com apresentação da universidade
- Página com a oferta formativa (cursos e programas)
- Área de acesso para docentes e estudantes
- Secção de notícias e eventos
- Formulários de contacto e candidatura

## 🚀 Tecnologias utilizadas

- HTML5, CSS3 e JavaScript
- GitHub Pages para alojamento
- [Framework opcional: Bootstrap, React, etc.]

## 📁 Estrutura do projeto
/ ├── index.html # Página principal ├── sobre.html # Sobre a universidade ├── cursos.html # Oferta formativa ├── contacto.html # Formulário de contacto ├── assets/ # Ficheiros estáticos (imagens, estilos, scripts) │ ├── css/ │ ├── js/ │ └── img/ └── README.md # Este ficheiro de descrição
